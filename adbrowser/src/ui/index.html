    Was das hier ist

    Ein Browser als Website: Du tippst eine Adresse ein, der Server ruft die Seite ab, wirft Werbung und Tracker raus und liefert das saubere Ergebnis in einen Frame. Dadurch läuft jede Seite werbefrei — auch auf Geräten ohne Adblocker, im Privatmodus, auf der Arbeitsschul-IP und auf Seiten, die im Netz gefiltert sind.
